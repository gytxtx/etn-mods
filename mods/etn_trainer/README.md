# etn_trainer / 修改器 mod

游戏内作弊面板。按 **F1** 开关；局内打开会自动暂停，主菜单/商店打开不暂停。

界面为纯代码构建的像素风面板：近黑底、1px 白框、暖金标题，左侧页签 + 右侧分区卡片。
标题栏实时显示 FPS（绿 / 黄 / 红阈值）；方向键/Tab 可导航，数字键 **1–6** 切页，
**Esc** 关闭（有确认框时先取消确认）。

## 页面

| 页 | 内容 |
|---|---|
| 数值 | 移速 / 射速 / 伤害 / 拾取范围 倍率滑条（0.1x–10x，带 1/2/5/10 快捷值）、三档预设、无敌、秒杀；底部显示本局实际数值与预设说明 |
| 资源 | 金币与青辉石两张卡片：实时余额、快捷加减、自定义数量；青辉石写入存档前二次确认 |
| 解锁 | 角色 / 服装 / 支援 / 社团的拥有进度条，一键全部解锁（写入存档，二次确认） |
| 辅助 | 生命条与回满血、额外减伤上限、护甲值加算，以及当前生命上限 / 护甲 / 减伤 / 无敌状态 |
| 调试 | 在场敌人 / 回合 / 倒计时；清屏、结束本回合；敌人列表可搜索、点击即生成 |
| 关于 | 版本与构建号、快捷键、开发者模式、常驻 HUD、关闭全部作弊、面板回到中央 |

## 行为约定

- **倍率每局归零**，不写存档；面板位置与 HUD 开关记在 `user://etn_trainer.cfg`。
- 倍率注入挂在 `PlayerData.player_ability_changed_end`：每次属性重算后重新乘一次，
  因此关开关即还原，且不会吞掉本局的自然成长（`reset_date()` 后也会自动重新生效）。
- 无敌走 `health_component.is_invincible`（会挡治疗，回血按钮内部临时关掉再治）。
- **非对局时**：数值 / 辅助 / 调试页显示「需要在对局中」说明；资源 / 解锁 / 关于仍可使用，
  其中金币卡因为没有玩家而禁用，青辉石与解锁可以正常写入存档。
- **进入联机会话（`ExtensionHooks.is_lan_session` 变为 true）时自动重置全部作弊**：
  四项倍率、减伤 / 护甲、无敌、秒杀与内存 dev_mode 全部归位，并立即重算玩家属性、同步面板；
  随后整体只读禁用。所有页（含关于）显示联机遮罩，确认框也会被拒绝，防止污染他人房间。
- 确认框是面板内模态：点击遮罩不会误触，Esc 先取消确认；「取消」默认获得焦点。
- 解锁会同时覆盖本体内容与 Mod 内容（角色用 `ModAPI.get_base_characters()` +
  `ModAPI.get_characters()`，社团用本体 + Mod 社团表）。
- 面板挂在 `get_tree().root` 下，打开时会把自己移到 root 末尾——本体 GUI 命中测试按
  场景树逆序走，不这么做会被新场景的背景 Control 抢走鼠标事件。
- 常驻 HUD 贴**右上角**（本体 HUD 占左上角），显示 FPS / 敌人数 / 回合 / 倒计时 / 当前加成；
  **只在局内显示**，标题 / 主菜单 / 商店等无玩家场景自动隐藏；联机只读时显示「联机只读」。

## 依赖

- 本体 **v0.5.1.4 及以上**（`Game.version_number`），`ModAPI.VERSION = 2`。

## 已知限制

- `tools/pack_mod.gd` 原样打包，**打不进 PNG 贴图**：`icon.png` 靠 zip 内的独立文件
  被安装器解到 `user://mods/etn_trainer/icon.png`，不在 pck 里。若将来需要贴图/翻译资源，
  改用本体工程副本 + `ModPack` 导出预设的构建路径。
- 面板字号/尺寸按本体基准分辨率 **640×360** 设计，改动前先确认 `project.godot` 的 stretch 设置。
- 面板与 HUD 只用 `StyleBoxFlat`、代码生成的像素图标和本体默认字体，不依赖额外贴图。
- 无头自检：`--headless --path <本体工程> --quit-after 400 -- --trainer-selftest [--trainer-scene=res://scenes/main/test_room.tscn]`。
